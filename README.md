Gobble Dash 3 — Thanksgiving Breakout! Pip the turkey refuses to become Thanksgiving dinner. Run 1500m through three zones — the Farmyard, the Pumpkin Orchard and the Kitchen itself — while Farmer Hank chases you with his carving knife: jump the glowing oven, duck the thrown knives, hide in haystacks while he searches, chain near-miss combos up to x8, and grab power-ups along the way — chili turbo with a flame trail, a shield feather that blocks one hit, and a corn magnet — then survive the final 120m Oven Gauntlet past the giant oven gate. Three lives, three zones, one very determined turkey. Pure static HTML/canvas — plays offline in a desktop browser, keyboard and mouse, no network requests, synthesised sound.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
