Gobble Dash — Last Turkey Out! Pip the turkey refuses to become Thanksgiving dinner. Outrun Farmer Hank (carving knife in hand) for 1200m through the Farmyard, the Barnyard and the Kitchen Run: jump the glowing oven and the hay, duck the thrown carving knives, dodge mud puddles, grab corn to refuel your dash, and sprint when the farmer lunges. Three lives, three stages, one very determined turkey. Pure static HTML/canvas — plays offline in a desktop browser, keyboard and mouse, no network requests, synthesised sound.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
