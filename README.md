Gobble Dash 2 — Last Turkey Out! Pip the turkey refuses to become Thanksgiving dinner. Run 1500m through three zones — the Farmyard, the Pumpkin Orchard and the Kitchen itself — while Farmer Hank chases you with his carving knife: jump the glowing oven, duck the thrown knives, hide in haystacks while he searches, chain near-miss combos up to x8, grab corn to refuel your dash and golden feathers for extra lives, and sprint when he lunges. Three lives, three zones, one very determined turkey. Pure static HTML/canvas — plays offline in a desktop browser, keyboard and mouse, no network requests, synthesised sound.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
